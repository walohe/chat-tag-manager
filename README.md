# Chat Tag Manager（聊天标签管理）

给 SillyTavern 的「管理聊天文件」页面加一层轻量的标签系统：给聊天打标签、按标签筛选、批量整理，还能量身定制地把模型和预设自动记成标签。数据只存在浏览器本地，不碰你的聊天文件，用得越久越顺手。

## 能做什么

- 聊天卡片上直接显示标签胶囊，点一下就能按这个标签筛选。
- 选择模式：勾选多个聊天，一次添加或移除标签。
- 标签分组可折叠：模型、预设、手动标签自动分开展示，列表再长也不乱。
- 自动打标签（可在设置里关闭）：每次 AI 回复完成后，自动记录当次模型和当前预设。
- 历史补标：一键扫描当前角色/群聊的聊天，把已有消息里的模型补成标签。
- 改名、删除、切换角色时，索引自动跟着迁移，不用手动维护。

实现上刻意做得很克制：整个扩展不修改聊天 JSONL，不拦截消息内容，只在 IndexedDB 里存一份本地索引，配置也全部在设置面板里。

## 安装

把 `chat-tag-manager/` 整个目录复制到：

```text
SillyTavern/data/<user-handle>/extensions/chat-tag-manager
```

也可以在 SillyTavern 的扩展管理器里输入本仓库地址安装。刷新页面后，打开左下角菜单 → 「管理聊天文件」就能看到工具栏里多了筛选和选择按钮。

最低客户端版本：SillyTavern 1.18.0。

## 快速上手

1. 打开「管理聊天文件」，点工具栏的双勾图标进入选择模式。
2. 勾选若干聊天，输入标签名，点「添加标签」。
3. 点卡片上的标签胶囊，就能只看打过这个标签的聊天。

想让它自己归类：打开「扩展 → 聊天标签管理」，确认「生成回复后自动打模型/预设标签」是开启的，之后新消息就会自动带上模型和预设标签；老聊天点一下「按聊天元数据补模型标签」补上。

## 设置面板

在「扩展 → 聊天标签管理」里可以：

- 开关标签显示，以及是否自动打模型/预设标签。
- 查看当前角色/群聊的标签，按模型、预设、手动分组管理，重命名或删除。
- 一键清空当前角色或当前用户的全部标签数据。

## 数据与安全

- 标签存在浏览器 IndexedDB（库名 `SillyTavern-Chat-Tag-Manager-v1`），按用户 + 角色/群聊隔离。
- 不修改聊天文件，不修改消息内容。
- 随时可以在设置里清空，不影响任何原始数据。

