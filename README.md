# Chat Tag Manager（聊天标签管理）

给酒馆（SillyTavern）加一个聊天标签插件，主要就是干这几件事：

- 给聊天打标签、按标签筛选、批量整理。
- 能自动把「模型」和「预设」记成标签，以后找聊天就不用一条条翻了。
- 标签按「模型 / 预设 / 手动」分组，可以折叠，列表长了也不乱。

标签仍会写入本地 IndexedDB 以便快速筛选，同时会镜像保存到当前聊天原生的 `chat_metadata.chatTagManager` 字段。打开聊天时会按更新时间自动恢复较新的版本，因此浏览器存储被清理或 IndexedDB 异常时也不会轻易丢标签。这个插件是 Codex 帮我写的，我基本没怎么操心，改起来也顺，确实省了我不少事。

## 怎么装

最方便的是用酒馆自带的「安装扩展」：

1. 打开酒馆，点顶部右侧的扩展图标，进「安装扩展」。
2. 把本仓库的链接填进去安装。
3. 它会装到 `public/scripts/extensions/third-party/chat-tag-manager`，刷新页面就能用。

如果不想在线装，也可以手动把 `chat-tag-manager` 这个文件夹整个丢到：

```text
public/scripts/extensions/third-party/chat-tag-manager
```

然后刷新页面。

## 怎么用

1. 左下角菜单打开「管理聊天文件」。
2. 点工具栏那个「双勾」图标，进入选择模式。
3. 勾选几个聊天后，点「输入标签」打开标签悬浮窗，输入标签名，点「添加标签」。
4. 点聊天卡片上的标签胶囊，直接筛选带这个标签的聊天，不会自动打开悬浮窗。
5. 点工具栏的漏斗按钮打开悬浮窗，仍可在里面输入或点击标签筛选；点击筛选框旁的 × 清除筛选。

标签筛选和手动输入使用屏幕内的悬浮窗，长标签自动换行。整个窗口纵向滚动，标签列表不再有单独的高度限制；手机键盘弹出时按可见屏幕重新调整大小。收起窗口保留筛选和未提交输入，点击筛选框旁的 × 清除筛选。

想让模型和预设自己打标签：打开「扩展 → 聊天标签管理」，把「生成回复后自动打模型/预设标签」打开。之后每次 AI 回完消息，就会自动记下当次模型和当前预设；老聊天可以点「按聊天元数据补模型标签」补一次。

## 设置面板里还能干嘛

- 开关「在聊天卡片上显示标签」。
- 开关「自动打标签」。
- 看当前角色/群聊的标签，按模型、预设、手动分组，可以重命名或删除。
- 一键清空当前角色或当前用户的全部标签。

## 数据说明

标签存在浏览器 IndexedDB（库名 `SillyTavern-Chat-Tag-Manager-v1`），按用户和角色/群聊分开，不修改聊天文件、不修改消息内容。
