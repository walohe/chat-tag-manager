# Chat Tag Manager｜聊天标签管理

给 SillyTavern 的聊天记录加上标签，让查找和整理更方便。

聊天多了，光看标题不容易找到想要的那一段。你可以给聊天添加自定义标签，也可以自动记录使用过的模型和预设，再按标签筛选聊天记录。

**主要功能**

- **点击标签直接筛选**：在「管理聊天文件」中点击聊天卡片上的标签胶囊，即可筛选聊天记录，不会自动弹出悬浮窗。
- **悬浮窗筛选**：点击漏斗按钮打开悬浮窗，可以输入筛选条件，也可以从已有标签中选择。关闭悬浮窗后仍保留筛选，点击清除按钮恢复全部记录。
- **批量整理**：进入选择模式，勾选多条聊天后统一添加标签。
- **自动记录模型和预设**：开启后，每次 AI 回复完成，自动将当前模型和预设记为标签。
- **标签分组管理**：按「模型 / 预设 / 手动」分组展示，支持折叠、重命名和删除。

**怎么用**

1. 打开酒馆的「管理聊天文件」。
2. 点击双勾按钮进入选择模式，勾选聊天。
3. 点击「输入标签」，填写标签名并添加。
4. 平时直接点击聊天卡片上的标签筛选，需要更多操作时再点漏斗按钮。

自动标签功能可在「扩展 → 聊天标签管理」中开启。已有聊天也可以尝试通过「按聊天元数据补模型标签」补充模型标签，结果取决于原记录中是否保留了相关信息。

**数据存储**

标签保存在当前浏览器的 IndexedDB 中，按用户及角色／群聊分别管理，不修改聊天文件和消息内容。换浏览器或清理站点数据前，请留意标签数据不会随聊天文件自动迁移。

**v0.4.4.1 更新**

基于 v0.4.4 调整筛选交互：点击聊天卡片上的标签直接筛选，不再自动打开悬浮窗；漏斗按钮和悬浮窗内的筛选功能继续保留。
